# Security policy

Please report vulnerabilities privately through **GitHub Security Advisories** ("Report a vulnerability" on the repository's Security tab). Please don't open public issues for them.

Include the Diorama version (`diorama --version`), your macOS version, and steps to reproduce. Leave out raw captures or transcripts that contain private code or credentials.

The threat model and data handling are described in [docs/security.md](docs/security.md).
